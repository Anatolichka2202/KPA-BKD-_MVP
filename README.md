# KPA-BKD MVP — диагностический инструмент ЯПС/ЯЛС

Узкая Qt-утилита ручной проверки обмена с ЯПС через ЯЛС: соединение, периодический обмен, разбор ответов и диагностический интерфейс.

## Состав

- `test_network.*`, `YPSProtocol.h` — обмен и протокол.
- `portfinder.*`, `configmanager.*` — обнаружение и конфигурация.
- `mainwindow.*`, `main.cpp` — приложение.
- [Описание утилиты](Doc%20TestYls.md) — проектная документация.

## Сборка

CMake объявляет C++17 и Qt6 Core/Widgets/Network/Core5Compat.

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt
cmake --build build
```

Сборка и работа с текущим оборудованием в рамках оформления не проверялись. [KPA_COMPLEX](https://github.com/Anatolichka2202/KPA_COMPLEX) содержит gitlink на эту утилиту, но это само по себе не обеспечивает сборочную интеграцию. Полезный диагностический режим сохраняется до проверенной замены.

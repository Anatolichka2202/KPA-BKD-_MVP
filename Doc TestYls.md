# Документация к тестовому приложению test_yls_qt

## Общее описание

Приложение предназначено для тестирования взаимодействия с ЯПС (Ячейка Пиросредств) через ЯЛС (Ячейка Локальной Сети) по UDP-протоколу. Используется для отладки и проверки работоспособности оборудования в составе системы БКД (блок контроля двигателя)

## Архитектура приложения

### Стек технологий
- **Язык**: C++ 17
- **Фреймворк**: Qt 6 (Core, Widgets, Network)
- **Сборка**: CMake 3.16+
- **Протокол**: UDP (пользовательский протокол ЯПС)

### Компоненты системы

#### 1. **Основные классы**

| Класс | Назначение | Зависимости |
|-------|------------|-------------|
| `MainWindow` | Главное окно приложения, управление UI | `YLSNetwork`, `PortFinder`, `ConfigManager` |
| `YLSNetwork` | Сетевое взаимодействие с ЯЛС | `QUdpSocket`, `QTimer`, `YPSProtocol` |
| `PortFinder` | Автоматический поиск порта приёма | `QUdpSocket`, `QTimer` |
| `ConfigManager` | Управление конфигурацией приложения | `QSettings` |
| `YPSProtocol` | Реализация протокола взаимодействия | STL (std::optional, std::array) |

#### 2. **Взаимосвязи компонентов**
MainWindow (UI)
├── YLSNetwork (сетевое взаимодействие)
│ ├── QUdpSocket (отправка)
│ ├── QUdpSocket (приём)
│ └── QTimer (периодическая отправка)
├── PortFinder (поиск порта)
│ ├── QUdpSocket (тестовый)
│ ├── QUdpSocket (слушающий)
│ └── QTimer (таймауты)
└── ConfigManager (конфигурация)
└── QSettings (INI-файл)

## Протокол взаимодействия

### Формат пакетов

#### Запрос к ЯПС (16+ байт)
[0] - номер ячейки (4)
[1] - команда (1 = срабатывание)
[2-9] - резерв (0)
[10] - маска (биты 0-7)
[11-15] - остальное (0 или мусор)
#### Ответ от ЯПС (40+ байт)
[0] - номер ячейки (4)
[1] - команда (2 = ответ)
[2-13] - резерв
[14] - обновлённая маска
[15-39] - остальное
### Логика работы протокола

1. **Клиент** отправляет UDP-пакет на ЯЛС (IP: порт 1080)
2. **ЯЛС** пересылает пакет на соответствующую ЯПС
3. **ЯПС** обрабатывает команду и возвращает ответ через ЯЛС
4. **ЯЛС** ретранслирует ответ на порт приёма клиента
5. **Циклическая работа**: ЯЛС продолжает пересылать маску, пока не получит новую команду

### Параметры по умолчанию
- **IP ЯЛС**: `192.168.0.230`
- **Порт ЯЛС**: `1080`
- **Порт приёма**: `100` (экспериментально определённый)
- **Номер блока**: `4` (тестовый блок)

## Конфигурационный файл

### Формат файла `config.ini`
**ini**
 **[network]**
 yls_ip=192.168.0.230
 yls_port=1080
 listen_port=100

 **[search]**
start_port=95
end_port=105

**[behavior]**
auto_connect=false
### Описание параметров
|Секция |	Параметр |	Тип |	Значение по умолчанию	| Описание |
|------|-----------|------|-----------------------|----------|
|network |	yls_ip |	string |	192.168.0.230 |	IP-адрес ЯЛС|
|network |	yls_port |	uint16 |	1080 |	Порт отправки на ЯЛС|
|network |	listen_port |	uint16 |	100 |	Порт  приёма ответов|
|search	|start_port|	uint16|	95	|Начальный порт для поиска|
|search	|end_port	|uint16	|105	|Конечный порт для поиска|
|behavior	|auto_connect	|bool	|false	|Автоподключение при старте|

# Пользовательский интерфейс
## Секции интерфейса
1. **Конфигурация сети**
Поля для ввода IP ЯЛС, порта ЯЛС, порта приёма

Кнопки "Подключиться"/"Отключиться"

Статус подключения

2. **Поиск порта**
Диапазон поиска портов

Кнопка "Найти порт"

Прогресс-бар и индикация состояния

3. **Управление командой**
Выбор номера блока (0-11)

Установка маски (0-255)

Настройка периодической отправки

Кнопка отправки команды

4. **Визуализация состояния**
- 8 лампочек (биты маски)

- Отображение отправленной/полученной маски

- Статус подключения

5. **Конфигурация приложения**
- Опция автоподключения

- Кнопка сохранения настроек

## Состояния интерфейса
Режим "Отключено" (начальный)
Кнопка "Подключиться" активна

Кнопка отправки команды неактивна

Лампочки красные

Статус: "Нет подключения"

Режим "Подключено"
Кнопка "Отключиться" активна

Кнопка отправки команды активна

Заголовок обновляется: "Подключено"

Статус: "Подключено" (зелёный)

Режим "Поиск порта"
Кнопки управления заблокированы

Прогресс-бар отображает прогресс

Статус показывает текущий проверяемый порт

## Рабочие режимы
1. Однократная отправка
Отправка одной команды при нажатии кнопки

Ожидание ответа от ЯЛС

Обновление состояния лампочек по ответу

Результат: Лампочка на плате ЯПС мигает

2. Периодическая отправка
Включение чекбокса "Периодическая отправка"

Установка интервала (10-5000 мс)

Непрерывная отправка текущей маски

Результат: Лампочка на плате ЯПС горит постоянно

3. Автопоиск порта
Запуск по кнопке "Найти порт"

Проверка портов в указанном диапазоне

Отправка тестовых пакетов и ожидание ответа

Автоматическое обновление поля "Порт приёма"

4. Постоянное прослушивание
После подключения сокет приёма постоянно слушает указанный порт

Все входящие пакеты обрабатываются как актуальное состояние

UI обновляется при каждом получении ответа

## Особенности реализации
1. Многопоточность и асинхронность
Все сетевые операции выполняются асинхронно

UI не блокируется при сетевых операциях

Использование сигналов/слотов Qt для межпоточного взаимодействия

2. Обработка ошибок
Валидация ввода параметров

Обработка ошибок сетевых операций

Информативные сообщения об ошибках

Восстановление после сбоев

3. Устойчивость к сбоям
Автоматическое освобождение портов

Защита от дублирования подключений

Корректное завершение при разрыве соединения

Сохранение состояния при ошибках
